# Lettering scans

Hand-made lettering for the menu's scratching post goes here, one PNG per word:

| File | Word |
|---|---|
| `title.png` | Red Dot Rescue, all three lines in one image |
| `play.png` | play |
| `cards.png` | cards |
| `help.png` | how? |

Each PNG needs a transparent background, light strokes (they sit on dark rope), and a tight crop around the letters. Leave the "o" in "Dot" as a hole: the red dot sits in it.

To switch a word from the code-drawn scratches to its scan, change its line in `src/menu/lettering.js`. That file shows the exact line to use for each.
